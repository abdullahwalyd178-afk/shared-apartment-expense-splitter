# بالعدل | Shared Apartment Expense Splitter

تطبيق عربي بسيط لحساب مصاريف السكن المشترك. يشتغل في المتصفح بدون تسجيل دخول، خادم، مفاتيح API أو اشتراك.

## التشغيل للمبتدئين

1. اضغط **Code → Download ZIP** في GitHub.
2. فك ضغط الملف بالكامل. لا تفتح الصفحة من داخل ZIP.
3. افتح `index.html` بمتصفح Chrome أو Edge أو Firefox.
4. ضيف السكان، وسجّل المصروف ومين دفعه واختار المشاركين فيه.
5. راجع الأرصدة واقتراحات التسوية. سجّل الدفعة بعد ما تحصل فعلًا.

يمكن تشغيله بخادم محلي لو حفظ البيانات غير متاح مع فتح الملفات مباشرة:

```sh
python -m http.server 8000
```

ثم افتح `http://localhost:8000`. على ويندوز يمكنك استخدام `py -m http.server 8000` لو أمر `python` غير متاح. يحتاج الأمر تثبيت Python مسبقًا، بينما الفتح المباشر لا يحتاجه.

## الإمكانيات

- واجهة عربية RTL متجاوبة مع الموبايل والكمبيوتر.
- إضافة حتى 50 ساكن، وتسجيل المصاريف والتصنيفات والتواريخ.
- اختيار المشاركين لكل مصروف بالتساوي، حتى لو الدافع مش واحد منهم.
- تعديل وحذف المصاريف مع إعادة حساب الأرصدة.
- حفظ محلي تلقائي، وبحث في السجل.
- اقتراح تحويلات لتصفير الأرصدة وتسجيل دفعات فعلية أو دفعات جزئية.
- تنزيل نسخة JSON واسترجاعها، وتصدير CSV بترميز UTF-8.
- عملة واحدة للحساب: EGP افتراضيًا، أو USD / EUR / SAR / AED قبل تسجيل أول حركة. تغيير العملة لا يحوّل مبالغ.
- زر مثال توضيحي ببيانات مصطنعة. لا يحتوي المشروع على بيانات سكان حقيقية.

## الحساب والتقريب

كل المبالغ مخزنة كأعداد صحيحة بالقرش/السنت. مثال: 100 قرش على 3 أشخاص تصبح 34، 33، 33 حسب ترتيب المشاركين. الرصيد الموجب يعني أن الشخص له فلوس، والسالب يعني عليه فلوس. الدفعات المسجلة تقلل الدين، والدفعة الزائدة تنشئ رصيدًا عكسيًا. اقتراحات التسوية تصفّر الحساب، لكنها ليست ضمانًا لأقل عدد تحويلات ممكن نظريًا.

المبالغ المسموحة من 0.01 إلى مليار، بحد أقصى رقمين عشريين. النسخة تدعم حتى 5,000 حركة في استرجاع JSON وحجم ملف لا يزيد على 2 MB. التقسيم في هذه النسخة متساوٍ فقط، لا نسب مخصصة ولا تحويل عملات.

## الخصوصية والحدود

البيانات محفوظة في `localStorage` في هذا المتصفح فقط، بدون تحليلات أو اتصالات شبكة من التطبيق. لا يوجد تزامن أو حساب مشترك حقيقي بين الأجهزة أو السكان. ليست خدمة بنكية ولا تُرسل أي أموال. تسجيل التسوية مجرد قيد يدوي.

**نزّل نسخة JSON احتياطية بانتظام.** مسح بيانات المتصفح أو استخدام الوضع الخاص أو تغيير المتصفح/مسار الملف قد يفقدك إمكانية الوصول للبيانات. الملف المصدر قد يحتوي أسماء ومبالغ، فاحفظه وشاركه بعناية. استرجاع نسخة يستبدل الحساب الحالي بعد تأكيدك ولا يدمج الحسابين. لا تدعم النسخة التحرير المتزامن في أكثر من تبويب. لو المتصفح يمنع الحفظ سيظهر تنبيه واضح.

حذف ساكن مرتبط بحركات مالية ممنوع للحفاظ على صحة الحساب. احذف الحركات المرتبطة أولًا إن احتجت. حذف الحساب بالكامل يحتاج تأكيدًا.

## للمطورين

لا توجد مكتبات مطلوبة للتشغيل، ولا خطوة build. الملفات الأساسية:

- `index.html`: الواجهة.
- `style.css`: تنسيق RTL واستجابة الشاشات.
- `core.js`: الحساب والتحقق من النسخ الاحتياطية.
- `app.js`: إدارة الواجهة والتخزين والتصدير.
- `core.test.cjs`: اختبارات باستخدام Node.js المدمجة.

شغّل الاختبارات باستخدام Node.js 18 أو أحدث:

```sh
npm test
```

تشمل الاختبارات دقة الكسور، حفظ كل قرش، اختيار المشاركين، الدفعات الزائدة، استرجاع البيانات، و1,000 حساب مولد بشكل حتمي. لا تُضمّن أي مفاتيح أو بيانات مالية شخصية في المستودع.
